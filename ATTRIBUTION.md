# Attribution

Parcel owner-of-record data is published by county governments. This project
queries those official public ArcGIS REST layers; it does not own the data.

Cite the county and layer URL on every result. Last verified 2026-09-02.

## Kane County, Illinois (FIPS 17089)

- Publisher: Kane County GIS; Supervisor of Assessments; County Clerk
- Layer: https://gistech.countyofkane.org/arcgis/rest/services/KanePINList/MapServer/0
- Layer name (as advertised): Kane.DBO.Parcels_v2025
- Copyright text from the service: "Kane County; GIS, Supervisor of Assessments, County Clerk"
- Owner field: TaxName

## Wake County, North Carolina (FIPS 37183)

- Publisher: Wake County GIS
- Layer: https://maps.wakegov.com/arcgis/rest/services/Property/Parcels/MapServer/0
- Layer name (as advertised): Property
- Owner field: OWNER

Use of each layer remains subject to the county's published GIS / open-data terms.
